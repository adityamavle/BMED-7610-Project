## Papers

### Feature-space selection with banded ridge regression
- Authors: Pierre Ablin, Alexander G. H. Wu, Shaul R. O. Nunez-Elizalde, Alex H. Williams, Bertrand Thirion, Jack L. Gallant
- Venue: *NeuroImage*, Volume 264, 1 December 2022, 119728
- DOI: https://doi.org/10.1016/j.neuroimage.2022.119728
- URL: https://www.sciencedirect.com/science/article/pii/S1053811922008497
- Notes:
  - Formalizes banded ridge regression for multi-feature-space encoding models.
  - Explains why separate regularization per feature space improves both prediction and interpretability.
  - Important for this project because the Shortclips combined model uses banded ridge / multiple-kernel ridge ideas directly.
